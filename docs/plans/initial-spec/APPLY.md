# 在现有 Themelios 工作区继续实现

本执行包交给负责实现的 Coding Agent。用户已经初始化本机工作区、环境和工具链，当前任务是实现 Themelios 的完整通用基础能力，交付可独立使用的软件。先读取工作区现有 AGENTS.md、包定义、构建脚本与锁文件，再把本包对应到实际目录。

## 当前工作区是实施入口

保留已经可用的 Bun/Cargo workspace、Agent 导航工具、格式检查和本地检查命令。Spec 的目录落点按能力对应；已有同职责模块直接完善。首次核对只解决包名、命令、当前代码与本规范的真实差异，随后开始功能施工。

用户提供的技术基线是 Bun 1.4.4、TypeScript 7.0.2、Zod 4.6.7、Rust 1.100.0、napi-rs 3.x；锁文件固定实际版本。其余依赖采用工作区已有、能够满足本规范的稳定版本；新增依赖锁定后使用其当前类型和文档。某个依赖的小版本 API 与研究记录有差别时，在所属适配器内调整调用，公共语义保持一致。

## 以一个可运行成果承接下一个成果

[实施计划](plan/implementation.md) 的依赖关系决定先后。每个单元给出确定的所有者、文件、输入、输出和必要操作；可以并行的工作在依赖表中指出。实现者按上下文和实际工作量合并或拆分内部步骤，提交保存有用进展。

接口类型见 contracts，持久格式见 schema。用包内 Zod schema 生成类型与外部参考；实例 API 直接调用完整能力。遇到已有代码与本次语义不同，修改定义和全部实际调用方，同步相关配置、持久化、测试及文档。

验证随真实能力接入：SQLite/CAS 事务与源坐标用确定性场景；外部模型用真实配置；协议用真实客户端；Native/Portable 在目标平台运行；库消费从工作区外安装正式 tarball。局部迭代运行对应窄检查，完整 `check:repo` 用于跨包集成与最终交付。
