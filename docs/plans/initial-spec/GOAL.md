# 实现并独立交付 Themelios

在已初始化的本机 Themelios 工作区，依照附件 `Themelios-Implementation-Spec.zip` 完成通用基础平台。最终交付可供外部应用安装的正式包、独立文档工作台、Windows/Ubuntu Portable，以及经过真实使用验证的源码、示例和文档。

先读本包 README、APPLY、架构、公共合同和实施计划，再按真实依赖推进。用户现有环境、锁文件与 Agent 工具链是施工基础；保留有效设置，直接补齐能力。包职责、公共值、接口、SQL、保存/取消/重载语义和完成行为已经在本包决定。私有组织、依赖接入细节及局部优化由你依据实际工作区处理。

实现范围涵盖安装/实例/会话、配置与诊断、网络/凭据、SQLite/CAS、通用时间、材料/成果/来源、Models/Prompt/Tasks、可扩展输入准备、SDK/CLI/HTTP/MCP/gRPC、离线维护和发行。文本与图像为核心，PDF 作为真实扩展；音视频按正式接口及应用启用的配方接入。Themelios、Nexus、Nous 分别持有通用平台、数值算子、认知业务。

按单元完成可运行操作，分段修改并保存。结构替换同步全部生产者、消费者、配置、持久化、测试与文档，删除淘汰实现及其专属支撑。使用现有单一检查入口，局部迭代只检查受影响能力。

贯穿完成三条使用路径：独立 Models/Prompt 脚本；文档工作台的材料→预览/编辑→模型→保存→来源→重开；仓库外库存应用的原子导入、历史查询与原件导出。协议使用真实客户端，Native 和 Portable 在目标系统运行，Portable 搬迁后继续可用。

继续完成已授权实现，无需逐步等待用户审查。遇到实际外部阻塞，说明具体缺项并继续其他可完成工作。交付正式 tarball、Portable、使用说明及准确执行结果；完成 Themelios 后停止本期，不延伸到 Nous/Nexus 业务或外部发布。
